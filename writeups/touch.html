Shell RDP as KioskUser

Login to Port 8443

The website requires a password to log in to the dashboard. Unfortunately, the password it asks for is not the one listed in the machine information.

Static Code Analysis

A static code analysis was performed to gather more information. The source code on the /login page shows a login hint: 

<div class="login-hint" title="The default password is the device serial number included in your DeviceHub packaging.">Forgot your password?</div>

Finding the Password

Given that this website uses the OPTIONS method, it's reasonable to assume that it uses an API for communication and is most likely still in a development environment (not yet in production). Run a health check on the API to investigate further and possibly identify the version and other details.

Recon

Finding Hidden Files

As a Windows user, we enumerate hidden files first, because hidden files may contain more important information than regular files. A new credential was found: root & HTB@irw4ys_DB!2026!

MYSQL RCE via Load Plugin

icacls.exe is used to see who owns a file or folder. We validate the MySQL plugin folder to confirm our permissions.

It has been confirmed that the user we are using is one of the owners or modifiers of this folder, so we are verified to be able to modify it. Therefore, this is one low-hanging-fruit path via the MySQL plugin. Link file UDF: rapid7/metasploit-framework — mysql UDF

Create a function with the library file that we added to the plugin directory, then load and test it with a shell command.

Decode it from hex, and we get a shell running as the NT AUTHORITY user.
